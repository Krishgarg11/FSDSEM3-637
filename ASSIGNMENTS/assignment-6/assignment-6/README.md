# Assignment 6 - Notes Portal (React + GraphQL, no REST)

Terminal 1:  cd server && npm install && npm start      -> http://localhost:4000/graphql
Terminal 2:  cd client && npm install && npm run dev    -> http://localhost:5173

Login (stored in server/data/users.json):  admin / admin123   or   student / student123
Notes (title, description, file name) are saved in server/data/notes.json,
uploaded files are saved in server/uploads.
